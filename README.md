# SmartSport · 恢复教练

基于 Apple HealthKit 的身体恢复评估与训练推荐 iOS App。读取心率变异性（HRV）、静息心率、血氧、呼吸频率、睡眠等健康数据，综合计算每日恢复评分，告诉你今天该猛练、该放松，还是该休息。

## ✨ 功能

- **每日恢复评分（0–100）**
  - HRV 评分（权重 30%）：对比个人基线 + 7 天趋势 + 稳定性
  - 静息心率评分（权重 25%）：偏离基线程度
  - 睡眠与负荷评分（权重 30%）：睡眠时长 + 连续运动天数
  - 基础指标评分（权重 15%）：血氧、呼吸频率
- **智能训练推荐**：按评分分档推荐运动项目和时长，结合你的运动偏好与训练目标（减脂 / 增肌 / 健康）
- **健康红线提醒**：血氧过低、静息心率持续上升、睡眠负债、连续运动过久等自动预警
- **女性生理周期追踪**：根据经期记录自动调整评分标准，经期推荐温和运动
- **数据可视化**：今日 24 小时心率 / HRV / 血氧曲线，近 7 天睡眠、近 30 天 HRV / 静息心率趋势，体重体脂变化（Swift Charts）
- **身体数据管理**：BMI、体脂率、肌肉量、骨盐量、基础代谢率自动计算与追踪

## 🔒 隐私

- **纯本地处理**：所有健康数据只从 Apple HealthKit 读取并在设备上计算，不上传任何服务器
- **无账号、无网络请求**：App 没有任何服务器端，也不收集任何分析数据

## 📱 运行要求

- Xcode 16.3+
- iOS 17.0+
- Apple Watch（可选，用于获取 HRV / 血氧 / 运动记录等更完整的数据）

## 🛠 编译运行

1. 克隆本仓库
2. 用 Xcode 打开 `SmartSport.xcodeproj`
3. 在 Signing & Capabilities 中选择你自己的 Apple Developer Team
4. 连接设备或选择模拟器，Run

## 🧠 评分逻辑概览

```
总分 = HRV×30% + 静息心率×25% + 睡眠负荷×30% + 基础指标×15%
       ± 睡眠负债 / 心率趋势 / 连续运动等修正项
       × 主观感受校准（10%）
```

另有多条一票否决红线：如血氧 < 90%、HRV 骤降 + 静息心率飙升同时出现时，强制建议休息。详细逻辑见 `RecoveryEngine.swift`。
